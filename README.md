# Rushabh Patil – Portfolio

A simple, responsive portfolio website built with plain HTML, CSS and JavaScript (no build step).

## Files
- `index.html` – page content
- `style.css` – styling (light and dark theme)
- `script.js` – mobile menu, theme switch, active nav link
- `assets/Rushabh_Patil_Resume.pdf` – resume used by the "Download resume" button

## Publish on GitHub Pages
1. Create a new repository on GitHub. For a personal site, name it `Rushabh-28.github.io`.
2. Upload all files and the `assets` folder to the repository root (drag and drop works on github.com).
3. Go to **Settings → Pages**, set **Source** to **Deploy from a branch**, choose `main` and `/ (root)`, then click **Save**.
4. After a minute your site is live at `https://rushabh-28.github.io/`.

## Update later
- Replace each project's "View on GitHub" link in `index.html` with the exact repository URL (they currently point to your GitHub profile).
- Replace the PDF in `assets/` with a newer resume, keeping the same file name.
